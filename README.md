# Supreme TLV — Luxury Real Estate

Premium real estate website built with React + Vite + Tailwind CSS.

## Stack
- React 18 + React Router
- Tailwind CSS + Radix UI
- Framer Motion
- Vite

## Setup
```bash
npm install
npm run dev
```

## Deploy
Push to GitHub → connect to Vercel or Netlify. Build: `npm run build`. Output: `dist`.
